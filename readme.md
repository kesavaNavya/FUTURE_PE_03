## 📌 Overview ##

The AI Subject Tutor Chatbot is a persona-driven educational assistant designed using prompt engineering and a no-code chatbot platform. It helps users understand academic concepts through clear explanations, examples, and interactive quizzes across subjects like math, science, and basic computer science.

This chatbot focuses on providing a supportive, patient, and structured learning experience, similar to a human tutor.

## 🎯 Objective ##

The goal of this chatbot is to:

Explain academic concepts in a simple, step-by-step manner

Assist learners with doubts in math, science, and computer science

Improve understanding through examples and quiz-based practice

## 🧠 Chatbot Persona ##

Role: AI Subject Tutor
Tone: Supportive, patient, informative
Behavior:

Breaks down complex topics into simple explanations

Uses examples before moving to advanced concepts

Asks follow-up questions to ensure understanding

Offers quizzes or practice questions after explanations

## 🛠 Tools & Technologies Used ##

Chatbot Platform: Chatbot.com (No-code)

Approach: Prompt Engineering & Knowledge-Based Training

Design Focus: Conversational flow, intent handling, and fallback logic

## 📚 Knowledge & Training Content ##

The chatbot is trained using short, structured knowledge articles covering topics such as:

Algae and Photosynthesis (Biology)

Algebra and Linear Equations (Mathematics)

Binary Search, Recursion, and Time Complexity (Computer Science)

Basic Physics concepts like Newton’s Laws

Each topic includes multiple user phrases to improve intent recognition and reduce fallback responses.

## 🔄 Conversation Flow ##

User is greeted with a welcome message

User asks a question related to an academic topic

AI Tutor provides a clear explanation

Bot optionally offers:

A deeper explanation

A short quiz or practice questions

If the query is unclear, fallback logic prompts the user to rephrase
